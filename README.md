# 🎲 RPG Deck

Um sistema de ficha de personagem para RPG desenvolvido em Python.

## 📌 Sobre o projeto

O RPG Deck é um projeto pessoal criado para estudar e praticar:

- Python
- Estruturas de dados
- Arquivos JSON
- Programação orientada a objetos
- Linux

O projeto também faz parte da construção de um futuro cyberdeck portátil para utilização em RPGs.
